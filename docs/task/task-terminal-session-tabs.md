## 背景与目标

### 当前问题

- 当前终端会话依赖滑动切换和会话总览，主工作区没有持续可见的传统标签栏。
- 同时打开多个会话时，用户难以快速确认全部会话并直接切换或关闭指定会话。

### 期望结果

- 在终端设置中提供“滑动切换”和“标签页切换”两种会话展示样式。
- 默认继续使用滑动切换，用户可以持久化选择标签页切换。
- 传统标签页仅改变根会话的展示与切换入口，保留分屏、隧道、SFTP、同步输入和连接状态。

## 范围

### 本次需要

- 新增终端会话展示样式偏好并提供设置入口。
- 新增传统标签栏，显示根会话名称、连接状态和关闭入口。
- 支持标签自动换行，最多显示三行；更多标签在标签栏内纵向滚动，活动标签自动滚入视野，并保持现有快捷键和触控板切换。
- 标签栏采用紧凑的 IDE 式扁平视觉，避免多行圆角卡片形成按钮堆叠感；活动标签使用底部强调线，关闭入口仅在活动或悬停时突出。
- 单行标签高度为 26px，活动强调线以 1px 高度完整覆盖对应标签底边。
- 切换标签后，待活动面板完成显示再自动聚焦该标签上次使用的终端分屏；快速连续切换时不得让过期标签抢回焦点。
- 标签以约 132px 为最小列宽，并随终端当前宽度自动计算等宽列；完整行填满可用空间，最后一个不完整行保持与前面一致的列宽，不拉伸少量标签。长名称在标签内省略。
- 传统标签模式下，隧道快捷入口浮在终端内容右上角，不占用标签栏宽度。
- 标签不显示悬停信息浮层；完整信息通过右键菜单中的复制操作获取。
- 标签右键菜单提供复制会话、重新连接、复制名称、复制主机地址、复制用户名、复制连接信息、复制当前目录和关闭会话等常用操作，并根据会话数据禁用不可用项。
- 切换样式后保持终端实例挂载，并触发现有终端尺寸适配流程。

- 不增加标签拖拽排序、固定标签或标签分组能力。
- 不修改当前默认展示样式。

## 关键规则与边界

- 标签只对应根会话，`isSplitChild` 会话继续在所属根会话内按分屏树展示。
- 关闭按钮只关闭对应根会话，并阻止点击冒泡导致无意义的先激活再关闭。
- 右键菜单操作始终作用于被右键点击的标签，不要求先切换为活动会话。
- 复制到剪贴板失败时必须给出错误提示，不静默失败。
- 会话为空、活动会话变化、标签换行与纵向溢出、设置取消时都应保持状态一致。
- 设置预览不得持久化；取消设置后恢复已保存样式。
- 样式切换不得卸载或重建 `Terminal` 组件。
